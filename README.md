# 배달 기록 앱

운행 중 GPS 경로와 콜 처리 과정(수락, 거절, 가게 도착, 픽업 완료, 배달 완료)을 기록하고,
일별·기간별·정산 화면으로 보여 주는 개인용 안드로이드 앱입니다.

## 설치 파일 만드는 법 (처음 한 번)

1. github.com 에 가입합니다.
2. 오른쪽 위 **+** → **New repository** → 이름 `RiderLog` 입력 → **Private** 선택 → **Create repository**.
3. 만들어진 페이지에서 **uploading an existing file** 링크를 누릅니다.
4. 압축을 푼 `RiderLog` 폴더 **안의 내용 전부**를 끌어다 놓습니다. `.github` 폴더도 꼭 포함해야 합니다.
   숨김 폴더라 안 보이면 아래 "숨김 폴더" 항목을 참고하세요.
5. **Commit changes** 를 누릅니다.
6. 위쪽 **Actions** 탭에서 빌드가 끝날 때까지 기다립니다. 3~5분 정도 걸리고, 초록 체크가 뜨면 완료입니다.
7. 저장소 첫 화면 오른쪽 **Releases** → 최신 항목의 `RiderLog-N.apk` 를 **폰에서** 눌러 받아 설치합니다.
   "출처를 알 수 없는 앱" 설치 허용이 필요할 수 있습니다.

### 숨김 폴더
- 윈도우: 탐색기 상단 **보기 → 표시 → 숨긴 항목** 체크
- 맥: Finder에서 `Command + Shift + .`

## 서명 키 설정 (처음 한 번)

저장소 **Settings → Secrets and variables → Actions → New repository secret** 에서
아래 두 개를 만듭니다. 값은 Claude가 따로 준 `GitHub_비밀값.txt` 파일에 있습니다.

- `KEYSTORE_PASSWORD`
- `KEYSTORE_B64`

이 키는 저장소에 올라가지 않고, 앱 업데이트가 같은 앱으로 인식되게 하는 데만 쓰입니다.
파일은 잃어버려도 괜찮지만, 비밀값을 지우면 다음 업데이트 때 앱을 지우고 다시 깔아야 합니다.

## 업데이트

코드가 바뀌면 같은 방식으로 파일을 다시 올리면 새 APK가 자동으로 만들어집니다.
서명 키가 고정이라서 **지우지 말고 그대로 덮어 설치**하면 기록이 유지됩니다.

## 처음 실행할 때 허용할 것

- 다른 앱 위에 표시 (오버레이 버튼)
- 위치 → **앱 사용 중에만 허용**이면 충분합니다. 운행 중에는 상단 알림으로 계속 실행됩니다.
- 알림
- 홈 화면의 **배터리 최적화 제외** 버튼 → 이 앱을 "제한 없음"으로 설정
  (삼성 폰은 이걸 안 하면 운행 중 기록이 끊길 수 있습니다)

## 데이터

- 모든 기록은 폰 안에만 저장됩니다.
- 홈 → **전체 데이터 내보내기** 로 JSON 파일을 만들어 Claude에게 주면 분석할 수 있습니다.
